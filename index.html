Free Deployment Guide 🚀
Deploy VitaForge free so it works on any phone, offline — no server needed.
Option 1 — GitHub Pages ⭐ Recommended
Step 1
Download this file
Right-click this page → Save As → vitaforge.html
Step 2
Create GitHub account
github.com → Sign Up (free). Takes 2 minutes.
Step 3
Create new repository
Click + → New repository → Name: vitaforge → Public → Create.
Step 4
Upload & rename file
Click "Upload files" → drag vitaforge.html → rename to index.html → Commit changes.
Step 5
Enable GitHub Pages
Settings → Pages → Source: branch main → / (root) → Save.
